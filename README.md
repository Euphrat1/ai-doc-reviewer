## ai-doc-reviewer (MVP)

Streamlit-приложение для сборки **Full Corpus → Prompt Corpus** из папки с файлами и отправки анализа в OpenRouter.

### Запуск
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

### Спеки
- `specs/tech_req.md`
- `specs/parsing_rules.md`
- `specs/ui_spec.md`
- `specs/promts.md`
